# Device Mirror

Device Mirror 是适用于 Apple Silicon / macOS 13 或以上的本地设备投屏与控制程序，支持 Android、iPhone、iPad 和 iOS 模拟器。每台设备使用独立窗口，可以同时连接多台设备。

## 开始使用

打开仓库根目录的 `Device Mirror.app`。应用内含 adb、scrcpy、原生控制服务及所需动态库，可移到“应用程序”等目录运行，日常使用不依赖源码目录或 Python。iOS 实时操控要求 iOS / iPadOS 27 或以上和完整 Xcode 27 或以上；USB 观看真机镜像使用 macOS 系统采集功能。

| 设备与用途 | 连接条件 | 操作入口 |
|---|---|---|
| Android 投屏与操控 | USB 调试及设备授权 | Android → 选中设备 → 开始投屏 |
| iPhone / iPad 观看镜像 | USB 连接、信任电脑、macOS 采集权限 | iOS → USB 真机 → 查看镜像 |
| iPhone / iPad USB 操控 | iOS / iPadOS 27+、Xcode 27+、开发团队、开发者模式及测试认证 | iOS → 配置 Apple 账号 → USB 操控 → 连接 |
| iOS 模拟器投屏与操控 | Xcode 27+ 和 iOS 27+ Runtime；低版本仅观看 | iOS → 选择模拟器 → 启动并连接 |

Android 支持点击、滑动、滚轮、键盘、中文与表情发送、虚拟设备按键、横竖屏切换和按设备记录 logcat。文字直接提交到输入框，保留设备剪贴板；首次发送需在设备上允许安装随应用提供的文本输入组件。投屏画面保持设备比例并贴合窗口可用区域。

iOS / iPadOS 27 及以上使用持续输入通道：鼠标按下立即发送触摸，拖动持续更新位置，松开结束，支持画面内长按。顶部设备按键分别发送按下、松开，按住时由系统处理长按；单次按住最多 30 秒。主页按钮立即开始底部上划，短按松开回主页，保持按住可进入多任务手势。普通拖动保持触摸输入，不转换为主页或返回请求。失焦、按 Esc、旋转、断线或关闭窗口会释放输入。

返回通过辅助功能定位当前页面明确的返回控件，再使用实时通道按下、松开；未找到控件时可尝试收起键盘。iOS 没有全局返回键，未标注的自定义控件需直接点击。文字和旋转仍使用 WebDriverAgent，真机连接时自动签名、安装该组件。画面回传及辅助功能查询仍有延迟；不传输 iOS 音频。低于 27 或无法确认版本时提示控制不支持，真机保留“查看镜像”，模拟器可仅观看。

27 通道已接入并通过本地输入阶段、报文及打包检查；当前设备为 iPadOS 26.3、模拟器 Runtime 为 26.5，已验证版本拦截，27 的真机与模拟器端到端操控尚待对应环境验证。

关闭设备窗口会停止该设备会话；⌘1 打开设备列表，⌘Q 退出全部会话。
